# Projekt zaliczeniowy – Dataset Manager

Projekt zaliczeniowy zrealizowany w języku Python w ramach przedmiotu
*wprowadzenie do data science*.

Celem projektu jest stworzenie modułu umożliwiającego podstawowe operacje
na zbiorze danych (dataset), takie jak wczytywanie danych, wyświetlanie informacji
o klasach decyzyjnych oraz podział zbioru danych.

---

## Zawartość repozytorium

- `main.py` – plik uruchomieniowy projektu
- `dataset_manager.py` – moduł zawierający implementację klasy `DatasetManager`
- `iris.csv` – zbiór danych Iris wykorzystywany w projekcie

---

## Wykorzystane technologie

- Python 3.x
- standardowe biblioteki Pythona (csv)

---
